# AI 스마트 고객관리 플랫폼 PRD

## 1. 제품 개요

### 제품명

**AI 스마트 고객관리 플랫폼**

### 한 줄 소개

> **AI가 고객을 분석하고, 누구에게 언제 무엇을 해야 하는지 알려주는 영업관리 플랫폼**

### 제품 목적

보험설계사와 상담·방문 영업인이 고객을 효율적으로 관리할 수 있도록 고객정보, 상담이력, 일정, AI 분석, AI 메시지 생성을 하나의 서비스로 통합한다.

기존 CRM처럼 고객정보를 저장하는 것에 그치지 않고 AI가 고객 데이터를 분석하여 **관리 우선순위, 다음 연락 시점, 상담 방향, 메시지**까지 추천한다.

---

## 2. 해결하려는 문제

현재 영업인은 고객이 많아질수록 다음과 같은 문제를 경험한다.

* 고객정보를 여러 곳에 분산해서 관리
* 마지막으로 언제 연락했는지 기억하기 어려움
* 어떤 고객에게 먼저 연락해야 하는지 판단하기 어려움
* 고객별 상담내용을 다시 확인하는 데 시간이 걸림
* 고객에게 보낼 문자를 매번 직접 작성
* 상담 후 기록을 남기는 것이 번거로움
* 장기간 관리하지 못한 고객을 놓침
* 고객관리 업무에 많은 시간을 사용

### 핵심 문제

**"고객정보는 가지고 있지만, 지금 어떤 고객에게 어떤 행동을 해야 하는지 알기 어렵다."**

---

## 3. 해결 방법

앱에 저장된 고객 데이터를 AI가 분석하여 영업인에게 다음과 같은 정보를 제공한다.

> **오늘 가장 먼저 연락해야 할 고객은 누구인가?**

> **왜 이 고객을 관리해야 하는가?**

> **언제 연락하는 것이 좋은가?**

> **무슨 내용으로 연락해야 하는가?**

> **고객에게 보낼 문자는 어떻게 작성할까?**

즉,

**데이터 입력 → AI 분석 → 우선순위 결정 → 행동 추천 → 메시지 생성 → 상담 기록 → 다음 관리 추천**

의 전체 과정을 자동화한다.

**보험설계사**

특히 고객 100명 이상을 관리하는 영업인을 주요 초기 고객으로 설정한다.

## 5. 핵심 사용자

> **AI 추천을 받은 고객에게 실제로 후속 행동을 했는가?**

예를 들어

AI 추천 고객 100명
→ 실제 연락 70명

이라면 **70% 실행률**을 목표로 합니다.

## 31. 개인정보 및 보안

이 서비스는 고객의 개인정보를 다루기 때문에 **보안과 개인정보 보호를 초기 설계부터 핵심 요구사항으로 포함**해야 합니다.

### 필수 고려사항

* 개인정보 최소 수집
* 암호화 저장
* 전송구간 암호화
* 접근권한 관리
* 로그 관리
* 개인정보 삭제 기능
* 이용자 동의
* 개인정보 처리방침
* AI API 전송 데이터 최소화

특히 고객의 민감한 정보가 AI 모델에 불필요하게 전달되지 않도록 데이터 처리 구조를 설계합니다.

## 32. 서비스의 핵심 경쟁력

이 앱의 핵심은 **CRM + AI**가 아닙니다.

정확하게는:

### 기존 CRM

**고객정보 → 저장 → 사용자가 판단**

### 우리 서비스

**고객정보 → AI 분석 → 우선순위 → 다음 행동 → 메시지 → 실행 → 기록 → 다시 AI 분석**

즉,

> **고객관리 데이터를 축적할수록 AI가 영업인의 업무를 더 잘 도와주는 구조**

를 만드는 것이 핵심입니다.
